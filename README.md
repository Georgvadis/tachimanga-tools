# Извлечение ссылок из TachiManga

В проекте лежит утилита, которая разбирает резервную копию `TachiManga` в формате `.tmb`, извлекает категории из библиотеки и сохраняет ссылки по категориям в текстовый файл.

По умолчанию утилита обрабатывает только эти источники:

- `E-Hentai`
- `Hitomi`

По доменам остаются только:

- `e-hentai.org`
- `exhentai.org`
- `hitomi.la`

## Файлы проекта

- `import/` — папка для исходных `.tmb`-бэкапов
- `extract_tachimanga_links.py` — основной скрипт
- `output/` — папка со сгенерированными файлами

## Что сохраняется в output

После запуска в папке `output/` создаются:

- `<backup_name>_ehentai_hitomi_by_category.txt` — ссылки, сгруппированные по категориям
- `<backup_name>_ehentai_hitomi_by_category.txt.skipped.tsv` — записи, которые не удалось экспортировать
- `<backup_name>_tachimanga.db` — исходная база данных `tachimanga.db`, извлеченная из резервной копии

Если в файле `.skipped.tsv` есть только заголовок, значит пропусков нет.

## Запуск

Запуск из корня проекта:

```bash
./extract_tachimanga_links.py import/Tachimanga_backup_2026-03-31_22-18-14-998.tmb
```

Исходные `.tmb`-файлы удобно складывать в папку `import/`.
По умолчанию результат будет записан в корневую папку `output/`.

## Указание другого пути

Можно передать свой путь к итоговому `.txt`:

```bash
./extract_tachimanga_links.py backup.tmb --output custom/result.txt
```

Если `--output` указывает на существующую папку, скрипт создаст в ней файл со стандартным именем.

## Формат итогового txt

В основном файле находятся:

- имя резервной копии
- список выбранных источников
- список разрешенных доменов
- блоки категорий вида `## НазваниеКатегории (число ссылок)`
- ссылки построчно внутри каждой категории
