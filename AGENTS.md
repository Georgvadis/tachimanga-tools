# Tachimanga tools — инструкции проекта

## Общий файл для агентов

`AGENTS.md` — источник инструкций проекта; `CLAUDE.md` — относительная ссылка
на него. Править нужно `AGENTS.md`, сохраняя ссылку: тогда Claude Code и Codex
читают одинаковые правила. Вложенные инструкции действуют только в своей папке.

- Общаться с пользователем по-русски, коротко и простыми словами.
- Коммиты и их описания — на английском; обычная работа идёт прямо в `main`,
  если пользователь явно не указал другую ветку. Не включать чужие изменения
  в коммит и не обходить хуки или подпись.
- Обновлять документацию затронутой функции и README, когда меняется его
  обзор, запуск или указатель документов; затем коммитить и публиковать.
- Проверки выполнять на изолированных данных. Реальные задания, заметки,
  коллекции, облачные ресурсы и внешние отправки не использовать как стенд.
- Деплой проверять только там, где проект подключён к Dockhand; локальная
  сборка не доказывает, что работающая установка обновилась.

`backup-tools/` — Python-утилиты резервных копий, без сторонних пакетов.
В этой папке дополнительно действует `backup-tools/AGENTS.md` с форматом `.tmb`
и историческими наблюдениями синхронизации. `extensions/` — Gradle и сборка
расширений; готовые артефакты публикуются в `gh-pages`, исходники — в `main`.
Настройка и выпуск — `extensions/docs/`, работа с копиями —
`backup-tools/README.md`, перенос репозитория — `docs/migration.md`.

Не менять оригинальные `.tmb`, cookies, ключ подписи и облачную библиотеку.
Работать с копией, сначала `--dry-run --no-api`, если команда это поддерживает.
Не читать и не выводить содержимое `~/.nsfw-ext.env` и `signingkey.jks`.
Выпуск расширений и облачная синхронизация — отдельные действия, не часть
проверки документации или обычной разработки.

Проверки: `python3 -m unittest discover -s tests -v`,
`python3 -m compileall -q backup-tools extensions/scripts`,
`bash -n extensions/scripts/build_repo.sh extensions/scripts/publish_pages.sh extensions/scripts/release_repo.sh`.
